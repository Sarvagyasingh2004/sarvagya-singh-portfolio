**Does he know TypeScript?**
Yes — it is his primary language. Both Kraftshala backend work and the

**How was this site built?**
Next.js frontend as a static export on S3 behind CloudFront with Origin Access
Control; the chatbot backend is Express 5 on EC2 behind an Nginx reverse proxy,
with MongoDB Atlas and Gemini. Both repositories deploy on push through GitHub
Actions using OIDC rather than stored access keys.
